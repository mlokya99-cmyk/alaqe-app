> **ئۇيغۇرچە ئالدىنقى ئورۇندا (Uyghur-First RTL) · تېز · بىخەتەر · زامانىۋى**

بۇ مەھسۇلات [alaqe-app-lahiye.md](file:///e:/OneDrive/Desktop/%D8%A6%D8%A7%D9%84%D8%A7%D9%82%DB%95%20%D8%A6%DB%95%D9%BE/alaqe-app-lahiye.md) لاھىيە ھۆججىتىگە تولۇق ئەمەل قىلغان ئاساستا قۇرۇپ چىقىلغان تېلېگرام ئۇسلۇبىدىكى مۇكەممەل ئالاقە سۇپىسى.

---

## 🌟 نۆۋەتتە ئەمەلگە ئاشقان ئىقتىدارلار (MVP)

1. **ئۇيغۇرچە RTL پۈتۈن گەۋدە لاھىيەسى:**
   - پۈتۈن كۆرۈنمە يۈز تەبىئىي ئوڭدىن سولغا (RTL) لاھىيەلەنگەن.
   - `Noto Naskh Arabic`، `UKIJ` فونتلىرى تولۇق سەپلەنگەن.
   - ئۇيغۇرچە ھەرپ كىرگۈزۈش نورماللاشتۇرۇش (Normalization) سىستېمىسى قوشۇلغان.
2. **ھەقىقىي ۋاقىتلىق ئالاقە (Real-time WebSocket):**
   - ئىككى تەرەپلىك دەرھال ئۇچۇرلىشىش (Latency < 200ms).
   - قارشى تەرەپ كىرگۈزۈۋاتقاندا «يازىۋاتىدۇ...» ھالىتى جانلىق چىقىش.
   - قوش بەلگە سىستېمىسى: `✓` ئەۋەتىلدى، `✓✓` ئوقۇلدى.
   - توردا / تورسىزلىق ھالىتى (Online / Offline Presence).
3. **ئاۋازلىق ئۇچۇر ۋە مېدىيا:**
   - بىر كۇنۇپكا بىلەن بىۋاسىتە مىكروفوندىن ئاۋاز خاتىرىلەش (Voice Recorder).
   - تېلېگرام ئۇسلۇبىدىكى ئاۋاز دولقۇنى بىلەن قويغۇچ (Waveform Audio Player).
   - رەسىم، پىكىر ۋە چوڭ ھۆججەتلەرنى يۈكلەش/چۈشۈرۈش.
4. **تېلېگرام ئۆلچىمىدىكى لاھىيە:**
   - قاراڭغۇ ئۇسلۇب (Telegram Desktop Dark Theme) ۋە يورۇق ئۇسلۇب (Light Theme).
   - سۆھبەت كاتېگورىيە تاللىغۇچىلىرى: «ھەممىسى»، «شەخسىي»، «گۇرۇپپا»، «كانال».
   - سۆھبەت ئىچى ۋە سىرتىدا تېز ئىزدەش كۆزنىكى.
5. **كىملىك ۋە سىناق ھېساباتلار:**
   - تېلېفون نومۇرى ئارقىلىق SMS OTP سىستېمىسى.
   - 1-چېكىش بىلەن ئالماشتۇرغىلى بولىدىغان سىناق ھېساباتلار (ئەلىشەر، دىلارە، بەھرام، ئالاقە بوت).

## 🚀 قوزغىتىش ۋە ئىشلىتىش

### 1. ئارقا سەپنى قوزغىتىش (Backend Server):
```bash
cd server
npm install
npm run dev
```
- REST API: `http://localhost:4000/v1`
- WebSocket: `ws://localhost:4000/v1/ws`
- تەكشۈرۈش بېتى: `http://localhost:4000/health`

### 2. ئالدى سەپنى قوزغىتىش (Frontend Client):
```bash
cd client
npm install
npm run dev
```
- توركۆرگۈچتىن ئېچىش ئادرېسى: `http://localhost:3001` (ياكى `http://localhost:3000`)

---

## 🧪 ئىككى ھېساباتتا بىرلا ۋاقىتتا سىناش ئۇسۇلى

1. توركۆرگۈچنىڭ ئادەتتىكى بېتىدە `http://localhost:3001` نى ئېچىپ، **ئەلىشەر** نامىدا كىرىڭ.
2. توركۆرگۈچنىڭ مەخپىي بېتىدە (Incognito Window) يەنە بىرنى ئېچىپ، سول ئۈستىدىكى تىزىملىكتىن «ھېسابات ئالماشتۇرۇش» ئارقىلىق **دىلارە** نامىدا كىرىڭ.
3. بىر تەرەپتىن ئۇچۇر، رەسىم ياكى ئاۋاز يوللىسىڭىز، ئىككىنچى تەرەپتە بىر دەقىقىدە، بەتنى يېڭىلىمايلا كۆرۈنىدۇ ۋە ئوقۇلۇش بەلگىسى (`✓✓`) بىلەن تەڭشىلىدۇ!
